# برنامج تعهدات مايل استون

المستودع الرسمي لتحميل إصدارات البرنامج وتحديثاته على Windows.

[تحميل أحدث نسخة](https://github.com/cryzerInd/milestone-undertakings/releases/latest)

## التحميل لأول مرة

نزّل ملف `Milestone-Update.zip` من صفحة أحدث إصدار، وفكّه في مجلد مستقل، ثم شغّل `برنامج تعهدات مايل استون.exe`. احتفظ بكل الملفات والمجلدات الموجودة في الحزمة. يحتاج البرنامج إلى .NET Framework 4.8.

## التحديث داخل البرنامج

اضغط «التحديثات» في القائمة الجانبية. إذا توفرت نسخة أحدث، احفظ المشروع الحالي ثم وافق على تنزيلها وتركيبها. يتحقق البرنامج من سلامة ملفات التحديث قبل التركيب، ويحتفظ بالمشاريع والبيانات المحلية. إصدار مستندات Word يعمل دون إنترنت.

يدعم البرنامج تعهدات الإصدار الجديد، وشهادة الإشغال، والقرار المساحي، والتجديد، والهدم، والإضافة والتعديل.

ملف `Milestone-Update.json` مخصص لآلية التحديث؛ لا تحتاج إلى تنزيله يدويًا.

# برنامج تعهدات مايل استون

المستودع الرسمي للتحديثات المشفرة لبرنامج تعهدات مايل استون على Windows.

[نسخة التثبيت الخاصة](https://github.com/cryzerInd/milestone-undertakings-private/releases/latest) · [أحدث تحديث](https://github.com/cryzerInd/milestone-undertakings/releases/latest)

## التثبيت لأول مرة

نسخة التثبيت الكاملة محفوظة في المستودع الخاص لحماية الحسابات والتوقيعات الموجودة في القوالب. سجّل دخولك بحساب GitHub المصرح له، ونزّل حزمة التثبيت الخاصة، وفكّها كاملة في مجلد مستقل ثم شغّل `برنامج تعهدات مايل استون.exe`. يحتاج إلى .NET Framework 4.8.

## التحديث داخل البرنامج

اضغط «التحديثات» في القائمة الجانبية. إذا توفرت نسخة أحدث، احفظ المشروع الحالي ثم وافق على تنزيلها وتركيبها. يتولى البرنامج التحقق وفك التشفير تلقائيًا، ويحتفظ بالمشاريع والبيانات المحلية. إصدار مستندات Word يعمل دون إنترنت.

يدعم الإصدار الجديد، وشهادة الإشغال، والقرار المساحي، والتجديد، والهدم، والإضافة والتعديل.

ملفا `Milestone-Update.enc` و`Milestone-Update.json` تستخدمهما آلية التحديث تلقائيًا. احتفظ بمجلد البرنامج كاملًا عند نقله إلى جهاز آخر، ولا تنشر حزمة التثبيت الخاصة في مكان عام.
